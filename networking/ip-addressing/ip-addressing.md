
# IPv4 Addressing Fundamentals

## What is an IP Address?
An IP address is a logical address used to identify a device on an IP network.

## IPv4
IPv4 is a 32-bit addressing system divided into four octets.

Example:
192.168.10.106

## Private IP Address Ranges

- 10.0.0.0 – 10.255.255.255
- 172.16.0.0 – 172.31.255.255
- 192.168.0.0 – 192.168.255.255

## Important Concepts

### Subnet Mask
A subnet mask identifies the network and host portions of an IPv4 address.

### Default Gateway
A default gateway is the router used to reach destinations outside the local network.

### Network Address
Identifies a particular IP subnet.

### Broadcast Address
Used to send an IPv4 broadcast to devices in a subnet.

## My Practical Example

My Windows PC reported a private IPv4 address in the 192.168.10.0/24 network.

- IP Address: 192.168.10.106
- Subnet Mask: 255.255.255.0
- Prefix: /24
