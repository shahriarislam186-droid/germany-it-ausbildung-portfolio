
# Practical 05: Network Connections with Netstat

## Objective
To inspect network connections and listening ports on Windows.

## Commands Used
```cmd
netstat -an
netstat -ano
```

## Concepts Practised
- TCP Connections
- UDP Endpoints
- Listening Ports
- Local and Foreign Addresses
- Process ID (PID)

## Observation
The commands displayed network connection information and associated process IDs where available.

## Learning Outcome
I learned how to inspect network connections and listening ports using netstat.
