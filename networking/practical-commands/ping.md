
# Practical 02: Ping and Connectivity Testing

## Objective
To test basic network connectivity using the Windows ping command.

## Commands Used
```cmd
ping 127.0.0.1
ping google.com
```

## Concepts Practised
- Loopback Address
- ICMP Echo Request and Reply
- Network Connectivity
- Packet Loss
- Response Time

## Observation
I tested the local TCP/IP stack and attempted to test connectivity to an external domain.

## Learning Outcome
I learned how to use ping to check basic network connectivity.
