
# Practical 04: MAC Address and ARP

## Objective
To inspect MAC addresses and the ARP cache using Windows commands.

## Commands Used
```cmd
getmac
arp -a
```

## Concepts Practised
- MAC Address
- Network Adapter
- ARP (Address Resolution Protocol)
- IP-to-MAC Address Mapping

## Observation
getmac displayed network adapter MAC addresses. arp -a displayed available ARP cache entries.

## Learning Outcome
I learned how to inspect MAC addresses and understand the relationship between IP and MAC addresses.
