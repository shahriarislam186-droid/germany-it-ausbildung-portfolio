
# Practical 03: DNS Lookup

## Objective
To understand how DNS resolves domain names into IP addresses.

## Command Used
```cmd
nslookup google.com
```

## Concepts Practised
- Domain Name System (DNS)
- DNS Server
- Domain Name Resolution
- IP Address Lookup

## Observation
The command queried a DNS server to resolve the domain name google.com.

## Learning Outcome
I learned how to use nslookup to investigate DNS resolution.
