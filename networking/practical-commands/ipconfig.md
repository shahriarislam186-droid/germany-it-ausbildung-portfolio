# Practical 01: Windows IP Configuration

## Objective
To inspect the local network configuration
using the Windows ipconfig command.

## Command Used
ipconfig

## Concepts Practised
- IPv4 Address
- Subnet Mask
- Default Gateway
- Local Network Configuration

## Result
Successfully inspected the network
configuration of my Windows PC.

## Learning Outcome
I learned how to identify the IPv4 address,
subnet mask and default gateway.
